# Coding Master

**Your Coding Journey, Organized in One Place.**

Coding Master is a personal coding productivity platform designed to help developers organize their coding journey, manage projects, connect coding profiles, and track their progress from one dashboard.

## 🚀 Features

### Currently Available
- **User Authentication:** Sign up and login using Supabase Authentication.
- **Public Exploration:** Explore the application without signing in.
- **Project Management:** Add, edit, delete, and manage personal projects.
- **Project Visibility:** Set projects as public or private.
- **Platform Connections:** Save and manage coding platform usernames.
- **Custom Appearance:** Dark mode, light mode, and 13 accent colour options.

### Coming Soon
- **Unified Practice History:** View daily coding activity across multiple platforms.
- **Contest Rating:** Track contest ratings and performance.
- **Code Vault:** A centralized space for storing coding solutions.
- **Analytics Dashboard:** Understand coding consistency and progress.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/gkashishgupta/Coding-Master.git
```

### 2. Navigate to the project

```bash
cd Coding-Master
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

### 5. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
